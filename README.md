# 📞 Call Center Analysis Dashboard  

## 📌 Project Overview  
This project analyzes call center operations using Excel, Python, SQL, and Power BI. The dataset was cleaned, transformed, analyzed, and visualized to identify key performance indicators (KPIs) and provide actionable business insights.

## 🎯 Objectives  
- Analyze overall call center performance.
- Measure call resolution and response efficiency.
- Evaluate agent performance.
- Monitor customer satisfaction.
- Build an interactive dashboard for decision-making.

## 🛠️ Tools & Technologies
- Microsoft Excel
- Python (Pandas)
- MySQL
- Power BI

## 📂 Project Workflow
1. Data Collection
2. Data Cleaning using Python (Pandas)
3. SQL Data Analysis
4. Dashboard Creation in Power BI
5. Business Insights

## 📊 Dashboard KPIs
- Total Calls
- Answered Calls
- Resolved Calls
- Average Speed of Answer
- Average Talk Duration
- Customer Satisfaction Rating

## 📈 Dashboard Features
- Calls by Agent
- Calls by Department
- Monthly Call Trends
- Answered vs Unanswered Calls
- Resolved vs Unresolved Calls
- Satisfaction Rating by Department
- Interactive Filters and Slicers

## 💡 Key Insights
- Identified top-performing agents.
- Compared department-wise call performance.
- Measured customer satisfaction trends.
- Tracked response time and call resolution.
- Highlighted areas for operational improvement.
